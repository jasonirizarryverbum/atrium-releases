# Atrium for Android

Installable builds of the Atrium Android app. The app checks this repository's
[latest release](../../releases/latest) and offers new versions at the top of the screen.

## Install

1. On the phone or tablet, open the [latest release](../../releases/latest) and download `Atrium-<version>.apk`.
2. Open the downloaded file. If Android asks, allow your browser (and later Atrium itself) to install apps.
3. Open Atrium. Enter your computer's Tailscale address and the pairing code from
   Atrium on the computer: **Settings → Phone → Pair a device**.

The app needs Tailscale on the device and Atrium running on the computer. It holds
no personal data until it's paired.
